# 🤖 IRCbot — دستیار هوش مصنوعی عمومی با مدل‌های محلی (Ollama)

[![CI](https://github.com/3punch/IRCbot/actions/workflows/ci.yml/badge.svg)](https://github.com/3punch/IRCbot/actions/workflows/ci.yml)
[![Python 3.10+](https://img.shields.io/badge/Python-3.10%2B-3776AB?logo=python&logoColor=white)](https://www.python.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-2ea44f.svg)](LICENSE)
[![Code style: ruff](https://img.shields.io/badge/code%20style-ruff-000000.svg)](https://github.com/astral-sh/ruff)
[![Ollama](https://img.shields.io/badge/Ollama-Local%20LLM-black?logo=ollama)](https://ollama.com)

یک ربات تلگرامی قدرتمند و همه‌منظوره بر پایه مدل‌های زبانی بزرگ محلی (**Local LLM**) با استفاده از **Ollama**؛ با حافظه مکالمه چندمرحله‌ای، پشتیبانی از مدل‌های استدلالی و پیشرفته، بدون وابستگی به اینترنت، تحریم یا پرداخت ارزی.

> 💡 **توسعه‌یافته بر پایه تجربیات پروژه [Amoozesh-Bot](https://github.com/3punch/Amoozesh-Bot):** بر خلاف Amoozesh-Bot که مختص انتخاب واحد دانشگاه و بررسی استادان بود، این بات دارای **موضوع آزاد و مکالمه عمومی (General Assistant)** مانند ChatGPT و Claude است و از مدل‌های سنگین‌تر و هوشمندتر، پنجره کانتکست وسیع و حافظه پیوسته بهره می‌برد.

## ❯ ویژگی‌های کلیدی

| بخش | توضیح |
|------|-------|
| 🌐 **موضوع آزاد و عمومی** | پاسخگویی به هر نوع سوال علمی، برنامه‌نویسی، نگارشی، ترجمه، تحلیل منطقی و گفتگوی روزمره |
| 🧠 **مدل‌های پیشرفته محلی** | سازگاری با مدل‌های قدرتمندی چون `Qwen 2.5 (14B/32B/7B)`، `DeepSeek-R1 (8B/14B)` و `Llama 3.3` |
| 💭 **پشتیبانی از مدل‌های استدلالی** | تفکیک خودکار و زیبای زنجیره تفکر (`<think>`) در مدل‌های Reasoning مانند DeepSeek-R1 |
| 🧵 **حافظه مکالمه (Multi-turn Context)** | حفظ سابقه گفتگو برای هر کاربر به صورت مستقل و امکان ارجاع به پیام‌های قبلی |
| 🎭 **شخصیت‌ها و پرامپت‌های متنوع** | تغییر سبک پاسخگویی (برنامه‌نویس، دانشگاهی، ادبی، صریح یا سفارشی) با دستور `/persona` |
| 🔄 **تغییر مدل آنی** | مشاهده لیست مدل‌های دانلود شده در سیستم و سوییچ لحظه‌ای بین آنها با دستور `/model` |
| ✂️ **شکستن هوشمند پیام‌های طولانی** | حفظ بلوک‌های کد (` ``` `) و پاراگراف‌ها در متن‌های بیش از ۴۰۰۰ کاراکتر بدون خطا در تلگرام |
| 🛡️ **کاملاً آفلاین و امن** | داده‌ها و پیام‌های شما از سیستم خارج نمی‌شود؛ بدون نیاز به API Key یا پرداخت هزینه |
| 🐳 **داکر و Docker-Compose** | اجرای کامل با یک دستور شامل سرویس Ollama و بات تلگرام |
| 💬 **پشتیبانی اختیاری از پروتکل IRC** | کلاینت آماده برای اتصال ربات به شبکه‌های گفتگوی IRC (مانند Libera.Chat) |

## ❯ مقایسه با Amoozesh-Bot

| معیار | Amoozesh-Bot | IRCbot (نسخه فعلی) |
|---|---|---|
| **حوزه موضوعی** | محدود به استادان و دروس دانشگاهی | **آزاد و همه‌منظوره** (کد، علم، هنر، چت، ترجمه) |
| **حافظه گفتگو** | تک‌پاسخ (Single-turn Q&A) | **حافظه پیوسته چندمرحله‌ای (Multi-turn)** |
| **سقف توکن پاسخ** | ۳۲۰ توکن (کوتاه) | **۲۰۴۸+ توکن** (مناسب برای کدهای کامل و مقالات) |
| **مدل پیش‌فرض** | `qwen2.5:7b` سبک | `qwen2.5:14b` یا `deepseek-r1:8b` (بسیار باهوش‌تر) |
| **پشتیبانی از استدلال (Reasoning)** | خیر (تگ‌ها خاموش) | **بله** (تحلیل و نمایش بخش تفکر `<think>`) |
| **انتخاب سبک گفتگو** | ثابت | **۵ شخصیت آماده + امکان پرامپت دلخواه** |
| **محدودیت سهمیه** | محدودیت روزانه ۳ پیام | **آزاد و بدون محدودیت** |

## ❯ شروع سریع

### پیش‌نیازها

۱. پایتون ۳.۱۰ یا بالاتر
۲. نصب [Ollama](https://ollama.com) روی سیستم یا سرور شما

### ۱) دریافت پروژه و ساخت محیط مجازی

```bash
git clone https://github.com/3punch/IRCbot.git
cd IRCbot

python3 -m venv .venv
source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
pip install -r requirements.txt
```

### ۲) دریافت مدل در Ollama

مدل دلخواه خود را در اولاما دانلود و اجرا کنید:

```bash
# پیشنهاد اول برای سیستم‌های با رم ۱۶ گیگابایت (بسیار قوی در فارسی و کدنویسی):
ollama pull qwen2.5:14b

# پیشنهاد عالی برای استدلال و تفکر ریاضی/منطقی:
ollama pull deepseek-r1:8b

# پیشنهاد برای سیستم‌های با رم ۸ گیگابایت:
ollama pull qwen2.5:7b
```

### ۳) تنظیم فایل `.env`

فایل نمونه را کپی کرده و توکن ربات تلگرام خود را وارد کنید:

```bash
cp .env.example .env
```

فایل `.env` را با یک ویرایشگر باز کنید و متغیرها را تنظیم نمایید:
```env
TELEGRAM_BOT_TOKEN=123456789:AAXXXXXXXXXXXXXX
OLLAMA_HOST=http://127.0.0.1:11434
MODEL_NAME=qwen2.5:14b
```

### ۴) اجرای ربات

```bash
python bot.py
# یا با Makefile:
make run
```

## ❯ اجرا با Docker Compose (یک‌کلیک)

اگر می‌خواهید Ollama و ربات تلگرام هر دو در کانتینرهای مستقل اجرا شوند:

```bash
# تنظیم توکن در فایل .env
cp .env.example .env

# اجرا با کامپوز
docker compose up -d
```

سپس برای دانلود مدل درون کانتینر:
```bash
docker exec -it local-llm-ollama ollama pull qwen2.5:14b
```

## ❯ دستورات ربات در تلگرام

| دستور | توضیح |
|---|---|
| `/start` | شروع کار با بات و نمایش منوی دکمه‌های سریع |
| `/new` یا `/clear` یا `/reset` | پاک کردن حافظه چت و آغاز گفتگوی تازه |
| `/persona` | تغییر سبک پاسخگویی (همه‌فن‌حریف، برنامه‌نویس، ادبی، دانشگاهی، صریح) |
| `/persona متن دلخواه` | تعریف پرامپت سیستمی سفارشی برای دستیار |
| `/model` | مشاهده وضعیت مدل و انتخاب مدل‌های دیگر نصب‌شده در سیستم |
| `/history` | مشاهده تعداد پیام‌ها و وضعیت نشست فعلی |
| `/help` | راهنمای استفاده و نکات کاربردی |

## ❯ شخصیت‌های آماده (Personas)

با دستور `/persona` می‌توانید سبک پاسخگویی را فوراً عوض کنید:
- 🤖 **دستیار همه‌فن‌حریف (پیش‌فرض):** متعادل، دقیق، با لحن دوستانه و فارسی روان.
- 💻 **مهندس نرم‌افزار:** تمرکز روی نوشتن کدهای استاندارد، دیباگ، معماری نرم‌افزار و Best Practiceها.
- ✍️ **نویسنده و ادیب:** خلاق، مسلط به نگارش شیوای فارسی، داستان‌سرایی و ویراستاری.
- 🎓 **استاد و پژوهشگر:** توضیحات گام‌به‌گام مفهومی با دیدگاه تحلیلی و آکادمیک.
- ⚡ **پاسخ صریح و خلاصه:** ارائه مستقیم نکات کلیدی بدون مقدمه و حاشیه.

## ❯ ساختار پروژه

```
IRCbot/
├── .github/workflows/ci.yml    # تست و بررسی کد در GitHub Actions
├── src/
│   ├── config.py               # مدیریت تنظیمات با Pydantic Settings
│   ├── logging_config.py       # پیکربندی لاگ‌های استاندارد
│   ├── llm.py                  # کلاینت ناهمگام ارتباط با Ollama و تگ‌های استدلال
│   ├── memory.py               # مدیریت حافظه گفتگو (Multi-turn Context)
│   ├── personas.py             # تعریف شخصیت‌ها و پرامپت‌های سیستمی
│   ├── formatter.py            # تقسیم هوشمند پیام‌های طولانی و بلوک‌های کد
│   ├── telegram_bot.py         # هندلرهای اصلی تلگرام (دستورات، پیام‌ها، دکمه‌ها)
│   └── irc_client.py           # کلاینت اختیاری اتصال به شبکه IRC
├── tests/                      # ۳۵ تست جامع واحد و یکپارچگی
├── .env.example                # قالب متغیرهای محیطی
├── Dockerfile                  # ایمیج بهینه ربات
├── docker-compose.yml          # اجرای خودکار همراه با Ollama
├── Makefile                    # دستورات سریع (make run, test, lint)
├── pyproject.toml              # پیکربندی روف، تست و متادیتا
├── requirements.txt            # وابستگی‌های قفل شده
├── bot.py                      # نقطه ورود ربات تلگرام
└── irc_bot.py                  # نقطه ورود کلاینت IRC
```
